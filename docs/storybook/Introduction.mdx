# Zone

**Zone** (`@angel1254mc/zone-ui`) is a general-purpose, _Zenless Zone Zero_–inspired React UI kit for game-flavoured web apps and sites. It is built with React 19 + TypeScript and borrows the game's visual language.

It is an unofficial fan project; Zenless Zone Zero and its art are © HoYoverse.

## Install and use

```bash
npm install @angel1254mc/zone-ui
```

```tsx
import '@angel1254mc/zone-ui/fonts.css' // optional: Mona Sans from Google Fonts
import '@angel1254mc/zone-ui/styles.css' // tokens + base styles + component styles
import { ZzzTheme, Button } from '@angel1254mc/zone-ui'

export function App() {
    return (
        <ZzzTheme>
            <Button>View</Button>
        </ZzzTheme>
    )
}
```

## Fonts and licensing

The kit's intended typeface is **Inpin Hongmeng** (印品鸿蒙体, weight 900), a **commercial** font that is not included. Instead we use **Mona Sans** (SIL OFL), a variable font loaded by `fonts.css`:

## State model

The core controls have **no hover state** by design, like a game menu driven by a pad or a mouse. The web components add hover where it helps; pressed always keeps the accent recipe. Open to changing this.

## Groups

- **Foundations**: [Tokens](?path=/docs/foundations-tokens--docs), [Materials](?path=/docs/foundations-materials--docs), [Accent Clock](?path=/docs/foundations-accent-clock--docs), [Sizing](?path=/docs/foundations-sizing--docs), [Stage](?path=/docs/foundations-stage--docs), typography, backgrounds, [Icons](?path=/docs/foundations-icons--docs), [Game Art](?path=/docs/foundations-game-art--docs) (the art used by the stories).
- **Primitives**: text, buttons, icon buttons, copy and sound toggles, key hints, badges, spinners, scroll areas.
- **Forms**: choice groups, tabs, sliders, chips, selects, switches, checkboxes, radios, text fields, pagination.
- **Data Display**: stat rows and tiles, charts, step and countdown progress, status grids, content cards, tables, pills.
- **Inventory**: rarity-coloured item cards, reward tiles and grids, for any collection or gallery.
- **Overlays**: dialog bands, modals, drawers, toasts, tooltips, menus, screen and sweep transitions.
- **Shell**: screen frame, top bar, bottom bar, page titles, web nav bar and footer, heroes.
- **Game**: event-style compositions (titles, ribbons, info pills, check-in calendar, mission cards).
- **Examples**: [ZZZ Daily Trivia](?path=/docs/examples-zzz-trivia--docs) and the Inter-Knot Dispatch news site, assembled only from the library.
