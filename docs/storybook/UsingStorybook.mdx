# Using this Storybook

Zone is a general-purpose, Zenless Zone Zero–inspired React UI kit for game-flavoured web apps and sites, and this Storybook is styled with it, like a ZZZ menu. The sidebar, search field, toolbar, tabs, addon panel and scrollbars all use the library's own materials, at a compact density (`--zzz-scale: 0.5`, 1 design unit = 0.5 CSS px at a 16 px root). The **Scale** control on the left of the toolbar is a real zone-ui `SegmentedTabs`, rendered inside Storybook's UI.

## Toolbar tools

### Scale: 0.5× · 0.7× · 1× · 1.333×

This sets the `zzzScale` global, which sets `--zzz-scale` on the `.zzz-theme` frame around every story. Sizes are rem-based (`--zzz-px = calc(1rem / 16 * var(--zzz-scale))`), so they also follow your browser font size and zoom.

- **0.7×** (the default) is the library's web default: md controls ~40 px tall and body text ~14 px at a 16 px browser font size, like other web design systems.
- **0.5×** is a compact density.
- **1×** is game density: 1 design unit = 1 CSS px.
- **1.333×** is a large density.

Full-screen, game-style scenes may render inside `<Stage>`, an optional artboard that fits its own canvas (default 1920 × 1080) to the story; everything else follows the Scale tool. See **Foundations / Sizing**.

## Finding things

- **Search**: the pill at the top of the sidebar. Press <kbd>Ctrl</kbd> + <kbd>K</kbd> to focus it from anywhere. Use ↑ / ↓ to move through the results (the highlighted one is accent-filled) and Enter to open it.
- **Tree**: the groups follow the library's layers: Foundations, Primitives, Forms, Data Display, Inventory, Overlays, Shell, Game and Examples. Inside the tree, ↑ / ↓ move between items (the keyboard row gets the accent focus ring), → / ← expand and collapse, and Enter opens the item. The selected story is the accent-filled row.
- **Addon panel**: <kbd>Alt</kbd> + <kbd>A</kbd> shows or hides it, and <kbd>Alt</kbd> + <kbd>D</kbd> moves it to the side. **Controls** edits a story's props. **Accessibility** runs axe on the current story.
